# Address Book## Project DescriptionThis project is a console-based Address Book application written in C++.The program allows users to manage different types of contacts, including:- Person- Business- Vendor- EmergencyThe application supports adding, editing, deleting, searching, filtering, saving, loading, and reporting contact information.---## Features### Contact ManagementThe program can:- Add a new contact- Edit an existing contact- Delete a contact- View one contact's full details- List all contacts### SearchingContacts can be searched by:- Name- Email- Phone number### FilteringContacts can be filtered by:- Contact type- City- Tag### Groups and TagsThe program supports:- Assigning contacts to groups, such as Family, Work, Vendors, or Emergency- Adding tags to contacts, such as Important, Client, Friend, Service, or VIP- Removing tags from contacts### File Import and ExportThe program can:- Load contacts from a CSV file- Save contacts to a CSV fileThe demo creates a sample `contacts.csv` file, loads it into the address book, saves the updated address book to `saved_contacts.csv`, and reloads the saved file to confirm that import and export work correctly.### ReportsThe program can generate these reports:- List contacts by type- Show contacts missing email or phone information- Display group summaries---## Files```textAddressBook.h      Function declarations for address book operationsAddressBook.cpp    Function definitions for address book operationsContact.h          Contact class declarationContact.cpp        Contact class implementationmain.cpp           Demo driver that tests all required featurescontacts.csv       Demo input file created by the programsaved_contacts.csv Demo output file created by the program
